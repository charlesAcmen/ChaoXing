# 超星视频增强倍速

一个零依赖的 Chrome / Edge Manifest V3 扩展，为超星网页中的 HTML5 视频播放器增加以下倍速：

`0.5x`、`0.75x`、`1x`、`1.25x`、`1.5x`、`1.75x`、`2x`、`2.5x`、`3x`、`4x`、`6x`、`8x`、`10x`、`12x`、`16x`

## 安装

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `D:\repos\ChaoXing`。
5. 刷新已经打开的超星课程页面。

## 实现说明

超星的学习页通过多层 iframe 加载课程卡片和视频播放器。扩展使用 `all_frames` 进入具有真实超星 URL 的 iframe：

- 在实际包含 `<video>` 的播放器 iframe 右下角显示固定悬浮按钮，不依赖可能被 Video.js 重建的内部控制栏；
- 点击选项后同时设置 `<video>` 的 `defaultPlaybackRate` 和 `playbackRate`；
- 监听 `ratechange`，让按钮文字和选中项与播放器实际速度保持同步；
- 不监听整棵 DOM，也不进入临时 `about:blank` iframe；
- 最多每 500 ms 查找一次视频，找到后立即停止，30 秒未找到也会自动停止。
- 选择大于 `2x` 时，如果页面在 `ratechange` 后立即强制暂停，仅在接下来的 1.2 秒内有限次数恢复播放；之后不会干预暂停操作。
- `10x/16x` 会启用当前视频实例的主页面倍速锁：维持目标倍速并忽略页面脚本触发的暂停；通过播放器真实点击暂停或按空格/K 仍会被识别并放行。切回 `2x` 或以下会立即解除锁定。
- 锁定期间，页面脚本针对该视频写入的 `1x/2x` 会被原生 setter 代理改回所选速度，避免超星在 `ratechange` 后把速度重置为 `1x`。

Chromium/Blink 当前对 `HTMLMediaElement.playbackRate` 的实现上限是 `16.0`，因此菜单最高设置为 `16x`。高倍速是否能流畅播放仍取决于网络、视频编码和设备解码能力。

扩展只改变用户主动选择的视频播放速度，不自动播放、自动跳课或修改学习进度。

## 同步调试窗口

页面右上角的“同步调试”窗口用于观察播放器自身的同步过程，不会创建、修改或重放任何进度请求：

- 汇总课程各层 iframe 中的 `play`、`pause`、`timeupdate`、`ended`、倍速锁和页面可见性事件；
- 记录 `fetch`、`XMLHttpRequest`、`sendBeacon` 的开始、完成、状态码、耗时以及请求发生时的视频位置；
- 对疑似同步请求显示 `playingTime`、`duration`、`attDuration`、`clipTime`、`isdrag` 等安全数值，并提取响应中的 `isPassed`、`success`、`status`、`code`、`msg` 等判定字段；
- 页面暂停被扩展拦截时，记录发起调用的脚本和行号，帮助区分切屏、答题 overlay 与播放器内部结算；
- 默认只显示疑似学习进度同步的请求，勾选“显示全部网络请求”可排查未知接口；
- “复制”导出最近 240 条事件，URL 查询参数和请求体只保留字段名；仅保留播放位置、时长、倍速等安全数值，不记录 Cookie、令牌或完整参数值。

调试窗口只能证明浏览器端发生了什么。HTTP 200 也不一定代表服务器已经把课程判定为完成，需要结合响应后的课程状态确认。
